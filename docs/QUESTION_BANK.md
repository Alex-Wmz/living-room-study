# 题库：内容与流程分开

文件为 UTF-8 JSON，`schemaVersion` 当前固定为 1。
最多 1 MiB、30 组课程、500 道题；每组课程至少一题。
额外字段会被拒绝，避免误把儿童身份或其他配置混进题库。

```json
{
  "schemaVersion": 1,
  "id": "my-course-bank",
  "title": "我的原创练习",
  "courses": [
    {
      "id": "arithmetic",
      "title": "数感练习",
      "subject": "数学",
      "stage": "自定学习阶段",
      "unit": "加法",
      "source": "本人原创，已核对答案"
    }
  ],
  "questions": [
    {
      "id": "addition-01",
      "courseId": "arithmetic",
      "prompt": "7 + 5 = ？",
      "choices": ["10", "11", "12", "13"],
      "answerIndex": 2,
      "explanation": "7 + 3 = 10，再加 2，得到 12。",
      "tags": ["加法"]
    }
  ]
}
```

`description` 和题目的 `tags` 可省略。其他示例字段为必填。
`id` 使用小写字母、数字、横线或下划线，1–48 位；同类 ID 不能重复。
`courseId` 必须引用已定义的课程；选项不能重复，答案必须是有效选项序号。
题干最多 320 字、每个选项 140 字、解析 480 字，适合大屏阅读。

校验文件时，先把自己的题库放在仓库外或被忽略的 `local/` 中。
例如文件名为 `local/my-bank.json`，命令**可整段复制执行**，检查只输出课程与题目数量：

```powershell
node tools/check-bank.cjs local/my-bank.json
```

错误时会提示问题类别，不会自动修正题目或猜答案。
导入题库会切换当前页面的内容并重置本轮状态；原题库的浏览器保存项不合并。
修改题目内容也会形成新的记录分组，避免同名不同题的错题记录串用。
记录分组标识只是内容桶，不是加密或安全身份。

正文按文字显示，不解释 HTML。不要借题目载入远程脚本或图片；本版不支持多媒体题。
正式题库须保留作者/授权来源，先核对事实、难度、选项唯一性和解析，再让孩子使用。
付费题库、教材整页、真实姓名、出生日期、学校或成绩单均不应进入此公开仓库。
