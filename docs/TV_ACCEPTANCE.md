# 电视实机验收表

**当前所有设备栏均待验。** 浏览器演示、逻辑测试、一个品牌的口碑和他人的 README 都不能替代以下记录。
本项目当前没有 APK、系统覆盖层、外部应用计时或开机接管实现。

每轮先保存自己有权保留的配置和素材，核对目标设备；地址、序列号、家庭画面和儿童资料只留本地。
公开反馈只记录不含唯一标识的型号、系统大版本、功能结果和失败类别。

| 验收项 | 通过条件 | 当前状态 |
| --- | --- | --- |
| 安装与授权 | 本人允许的安装/调试路径，目标明确，不依赖关闭安全校验 | 待验 |
| 应用入口 | 桌面可见、图标可辨、Leanback/实际系统入口有效 | 待验 |
| 遥控器 | 全流程只用方向键、确认、返回即可完成，焦点始终可见 | 待验 |
| 分辨率与距离 | 720p/1080p 实际屏幕和观看距离可读，无裁边或按钮不可达 | 待验 |
| 题库 | 人工审过的版本与导入一致，非法文件不替换旧库 | 待验 |
| 定时与待机 | 明确计时口径，待机/唤醒后不重复、不漏、不误锁 | 待验，原生计时未实现 |
| 其他应用 | 逐个验证目标播放器，明确暂停/覆盖/提醒能做到哪一步 | 待验，系统适配未实现 |
| 开机与异常恢复 | 冷启动、进程回收、权限撤销后行为有记录与可用退出 | 待验，开机适配未实现 |
| 家长恢复 | 不依赖联网，有清楚的退出、停用和卸载路径；不留覆盖层 | 待验 |
| 升级与回退 | 同一签名/应用身份升级，数据保留可核对，旧可用版可恢复 | 待验，尚无 APK |
| 隐私 | 无多余账号/采集权限，题库和记录没有未经同意上传 | 待验 |
| 长期使用 | 至少一次完整目标时长的连续运行、待机恢复和异常退出 | 待验 |

真实家庭使用还需与家长、孩子确认规则和退出方式；不从短时技术测试推断教育效果。
任何一项失败，记录现象和范围，不用“应该支持”“小米最好”替代验收。
