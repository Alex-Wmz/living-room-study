# 当前状态与接力入口

更新时间：2026-11-05。版本：`0.1.0-preview.1`。本文件是公开源码的稳定接力入口。

## 本轮范围

已完成通用实现指南、独立网页参考实现、课程题库契约、18 道原创示例、
本机只读预览服务、校验工具和明确清单打包器。代码实现使用 AI 辅助。
没有复制第三方电视锁、新闻视频、教材原文、家庭设备资料或其他私人项目源码。

本轮用户选择：先交付通用指南与可运行演示；不以实体电视实测作为本轮交付内容。
自有内容按 PolyForm Noncommercial 1.0.0 发布；商业使用另行授权。

## 已验证

- Node.js 逻辑检查 16 项：题库/浏览器示例一致、契约与大小、歧义选项、重复 ID、非法 UTF-8、课程隔离、错题优先、有限会话及超时计算。
- Python 检查 6 项：本机服务仅提供白名单文件、私有/非运行路径拒绝、HEAD 与写入边界，以及运行 ZIP 的清单/许可/摘要和相同输入的可重复打包。
- 实际浏览器：课程与答题页面、正误反馈、完整三题记录、错题优先、Esc 返回、20 秒倒计时自动切题、无效题库拒绝、合成题库切换和文本安全呈现、本地导出读取、记忆开关及焦点返回。
- 浏览器布局：默认窄栏及 1280×720 视口检查；保存了内置原创示例的实际页面截图，不是电视实拍。
- [答题页的实际截图](../assets/demo-quiz.jpg) 使用内置演示题；不是第三方视频或家庭电视画面。
- 运行资源为本地文件，已检查本机 HTTP 运行页面无应用控制台错误。

发布前按文件清单审查源码与单次提交历史，核对 ZIP 实际条目、CRC、逐文件摘要、
截图/图像元数据与本机身份/凭据模式；发布后回读 commit、标签、Release 和附件摘要。
远端阶段的完成以 Git 记录、发布回执和远端读取为准，不把本地文件存在当成已经公开。

## 仍待验与未实现

电视实机的安装、遥控器、系统权限、后台存活、待机恢复、开机触发、覆盖其他应用和长期运行均未验。
本版没有 APK、外部视频计时、广告替换、防绕过、家长 PIN 或应用远程管理服务。
文件选择器与文件保存的跨浏览器/电视行为仍须逐环境验证；当前 UI 校验包含 JSON 编辑与本机下载回读。
自动浏览器明确禁止 `file://`，本轮未绕过，双击 HTML 的文件协议启动待验；已通过的是本机 HTTP。
内置题未对齐具体教材或年级大纲，不能用演示通过推断学习效果。

## 下一步从哪里继续

1. 先按 [实现指南](IMPLEMENTATION.md) 约定具体家庭使用流程、退出方式和目标机型。
2. 有实体电视/盒子时，从 [真机验收表](TV_ACCEPTANCE.md) 开始记录，逐项保留失败范围。
3. 原生适配保持 `web/core.js` 与 JSON 数据契约，独立处理系统能力；不要让网页桥暴露任意系统命令。
4. 发布任何实机版之前重新检查签名、许可、数据与最终 APK/ZIP，保留可恢复的旧可用版本。

本地启动命令在 README；停止本机预览服务使用该终端的 Ctrl+C。
回退使用先前已核验的标签/发行包，不覆盖用户导入内容、不迁移其他设备的私人配置。
